# **TrueMood - Emotion Recognition ( Android App )** 
This repository contains the Android application for **TrueMood**, a real-time emotion recognition system. The app integrates a pre-trained Convolutional Neural Network (CNN) model to detect and display human emotions from facial expressions using the device camera.

<br/>

## Features
- Real-time emotion detection (Angry, Disgust, Fear, Happy, Sad, Surprise, Neutral).
- Displays results instantly via a user-friendly interface.
- Powered by a TensorFlow Lite model optimized for mobile devices.
