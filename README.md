## **TrueMood - Emotion Recognition ( Android App )** 
This repository contains the Android application for TrueMood, an emotion recognition system. The app integrates a pre-trained machine learning model to detect and display human emotions


The model training and core logic for emotion recognition are developed in a separate repository.
- ✅ **Visit it here :** [GitHub Repo](https://github.com/achelmasoudi/TrueMood_EmotionRecognition_ModelTraining)
